EMB 交接 / UVWLock 修正 — 變更紀錄

Longwin HallFOC ReGen V2.4 CAN · 馬達停車交接與低速再加速問題

摘要

本次處理兩個客戶回報問題,皆與低速時的 UVWLock(UVW 三相短路平順停車)機制相關。

#症狀路面修正
問題 1 減速停車時馬達無法在電磁煞車(EMB)夾緊前鎖住車輪,車輛先倒溜再被 EMB 鎖住 → 抖動 斜坡 Modified Plan A + Plan B
問題 2 減速接近停止時再催油門,馬達要等停車程序跑完才有反應 平路 UVWLock 解除條件改用油門目標

問題 1斜坡倒溜 + 抖動

根因

停車交接存在「沒人管的空窗」:馬達卸力/UVW 短路在 靜止時無靜態保持扭力(短路煞車力 ∝ 反電動勢 ∝ 轉速,靜止時為 0),而 EMB 從下命令到 機械夾緊有數十~上百 ms 延遲。平路無重力故無感;斜坡上重力在此空窗把車往後拉 → 倒溜 → EMB 突然咬住 → 抖動。

對策

Plan AUVW 短路後延遲鎖定 EMB(延遲可調):UVW 短路維持平順停車,計時達 EMBRAKER_SHORT_TO_LOCK_DELAY_MS 後鎖 EMB,讓機械夾緊時機對齊車速到 0。

Plan B反向霍爾邊緣即刻鎖定:速度回授在低速不可靠,但方向(霍爾狀態序列)在第一個反向邊緣即可判定。一偵測到倒溜(輪端約 3mm)立即鎖 EMB,繞過延遲。減速比 5:1 放大了角度解析度。

問題 2平路低速再加速沒反應

根因

UVWLock 的解除判斷用的是斜坡後的命令 inReference = ActiveRpm,而非油門目標。減速近停進入短路後再催油門,TargetRpm 雖立刻變大,但 ActiveRpm 只能沿斜坡慢慢爬,必須爬過 UVWLockSpeed(≈1966)短路才解除 → 表現為「油門沒反應,要等停完」。與坡度無關。

對策

在 UVWLock 維持條件加入油門目標判斷:只要 TargetRpm 超過門檻即立即解除短路,恢復即時加速。單純停車時 TargetRpm≈0,行為與原本相同。

上機驗證清單

  • 用 MPLAB X / XC16 編譯通過。
  • 平路:正常滑行/短路停車仍平順、不抖,EMB 行為不變。
  • 平路:減速近停立刻再催油門 → 馬達立即加速(問題 2)。
  • 斜坡:鬆油門停車 → 倒溜量明顯縮小(目標約數 mm)、抖動消失(問題 1)。
  • 調 EMBRAKER_SHORT_TO_LOCK_DELAY_MS:量測煞車機械夾緊延遲,調到「夾緊 ≈ 車速到 0」。預設 300ms 為起點。
  • 確認倒溜時 uGF.Direction 會在反向霍爾邊緣更新(UVW 短路下霍爾掃描仍運作)。
  • 確認 uGF.CtrlMode == 0(速度模式)。
備註:EMB 更新跑在主迴圈、在 UVWLock 重算之前,故 bEmbUVWLockActive 用的是上一迴圈的值(一個週期延遲,對 ms 級延遲無影響)。若 bUVWLockActive/bReverseEdgeDetected 皆為 false,狀態機自動回退原速度/逾時邏輯(安全預設)。
