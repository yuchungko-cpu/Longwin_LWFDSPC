Project: Longwin_LWFDSPC_V0.0 / Generated: 2026-07-08

Scope本文件整理本輪針對馬達堵轉、EMB、UVW lock、相電流尖峰、速度 profile CPU 負載，以及電流限制設定所做的韌體修改。

2. Motor Lock Test Mode

  • 新增 CODESW_MOTOR_LOCK_TEST_ENABLE，預設為 0，避免 production build 誤開。
  • 新增 CODESW_MOTOR_LOCK_TEST_PHASE_CURRENT_A，測試模式限制最大 phase current 為 5A。
  • 測試模式下 EMB 會保持 lock，用來模擬馬達堵轉狀態。
  • 測試模式下 8 秒堵轉降流後，5A 會再乘 50%，等效約 2.5A。

3. EMB 相關修改

問題 處理 狀態
懷疑 EMB lock 造成 throttle release current spike 曾加入 EMB lock 前清 motor command 的邏輯，並短暫做 EMB disabled 隔離測試。 已確認 spike 不是 EMB 造成。
EMB locked + 0 RPM 時偶爾 phase current 停在 1~2A 在 throttle / VR 更新後再次檢查 EMBRAKER_STATE_LOCKED；若 target RPM 為 0，呼叫 MotorStallForceOutputZero()，避免後段流程把 uGF.Coast 打回 0。 待實車再次確認。
EMB disabled test build 測試時曾將 CODESW_EMBRAKER_ENABLE 改為 0 並保持 OEMB release；測試結束後已恢復 1。 已恢復 normal mode。

4. UVW Lock 修改

實測確認 throttle release 的 current spike 由 UVW low-speed lock / 三相短路進入瞬間引起。後續未關閉 UVW lock，而是調整進入條件。

  • CODESW_UVW_LOCK_ENABLE 目前為 1，UVW lock 仍啟用。
  • 進入條件增加 ReferenceRAW == 0、ctrlParm.qVelRef == 0、低速、低 Id/Iq。
  • 需要連續穩定 500ms 後才允許 uGF.UVWLock = 1。
  • UVW_LOCK_ENTRY_CNTR 已配合 speed profile task 改為 500，代表 500 x 1ms = 500ms。

5. Speed Profile CPU 負載

原本 throttle / speed profile / outer speed PI 在 ADC ISR 中每 50us 執行一次，對 high-level speed command 來說過快。

  • 新增 s_u32LastSpeedProfileTimeMs gate。
  • throttle、acc/deacc profile、outer speed PI、UVW lock debounce 改為 1ms 執行一次。
  • D/Q current loop、Park/Clarke、SVPWM、PWM update 仍保持 ADC ISR fast loop。
  • RD13 speed profile debug pulse 現在代表 1ms profile task 的執行時間。

6. Max Phase Current / Torque Limit

  • 目前真正限制 phase current command 的主路徑是 piInputOmega.piState.outMax/outMin，也就是 speed PI output limit。
  • 該 output 會成為 ctrlParm.qVqRef，再作為 piInputIq.inReference。
  • normal temperature zone 目前使用 LOGIC_TEMP_CONTROLLER_RATIO_NORMAL = 0.31f，以 RATED_CURRENT = 50A 計算約 15.5A。
  • piInputIq.piState.outMax 是 Iq current PI 的 voltage output limit，不是 phase current command limit。

  • 移除未使用的 MOTOR_STALL_IQ_DETECT_THRESHOLD。
  • 移除主迴圈內未使用的 Longwin floating point test 計算，避免每圈執行 float multiply/divide。
  • 將 temp_qref_pow_q15 從 volatile local 變數改為一般 local 變數。
  • 當 CODESW_UNIFIED_LED_LOGIC_ENABLE == 1 時，不再於 ADC ISR 增加舊 LED counter。
  • 保留 a_Reg accumulator A 綁定，但移除 volatile，已消除 XC16 register-variable warning。

9. 仍需注意 / 後續建議

  • 命名改善：i16CurrentLimitA 實際是 Q15 ratio，不是真正 Amp 值，建議後續改名為 i16CurrentLimitQ15。
  • 函式命名：MotorStallForceOutputZero() 目前被用作通用 motor output zero helper，名稱可再整理。
  • 效能優化：throttle voltage-to-RPM mapping 仍可進一步用 cache 或預先計算 gain，降低 runtime division。
  • 實車驗證：EMB locked + 0 RPM 時 phase current 是否穩定歸零仍建議再測。
