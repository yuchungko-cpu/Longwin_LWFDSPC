LWFDSPC 版本變動對照　V0.16 → V0.19

2026-08-07　|　Modbus ID03 0x0015：0x0016 → 0x0019　|　V0.x 皆為內部測試版

本次變動的主線：為改善上坡起步而提高速度環增益（V0.18）→ 副作用是減速頓挫與多個潛伏問題現形 → V0.19 補上減速命令濾波、修好段位 0 電子鎖車、並把停車判定調回原設計值。

柔順度與制動距離是直接取捨。現值曲線 2 的制動距離約為原本（≈曲線 5）的 2.1 倍。 這是本版最需要實車量測的項目 —— 見第 5 節測試表第 1 項。
為何減速的 K 必須遠小於加速的 K：加速全程約 3200 ms，τ=256 ms 只佔 8%，磨圓了但延遲感覺不出來； 減速全程僅 240～1200 ms，同樣的 τ 會佔一半以上，停車時間會加倍。故減速 K 取 3～6（τ=16～128 ms）， 維持「τ／全程」比例在 7～13%。這是加速與減速不能共用參數的量化理由。

4Bug 修正

#問題V0.16 的實際行為V0.19 修正方式
1段位 0 仍以 1 km/h 前進
（e-lock）		 油門送出 1500 counts（1.04 km/h）。V0.16 因釋放門檻 1600 使 EMB 保持夾住，車不動但馬達頂著煞車堵轉 （互鎖只在「EMB 鎖定且目標為 0」才切斷出力）。門檻降到 800 後變成真的潛行。倒退則完全不受段位管制 段位 0 直接把目標歸零並繞過三道 OUTPUT_MIN 地板；不分方向，前進與倒退一次擋掉。 EMB 新增 bELockActive 閘門，任何命令來源都無法在段位 0 放開煞車。 刻意不做立即硬鎖 —— 行進中切到 0 段會平順減速到停後才鎖
2段位索引越界讀取 LCD 經 Modbus 送 4 bit（0～15），段位上限表只有 6 筆，索引前無邊界檢查 → 段位 6～15 讀取陣列外記憶體 夾到 THROTTLE_ASSIST_LEVEL_COUNT - 1，段位 6～15 行為等同段位 5
3靜止時 Speed 未歸零 MotorStartSpeedPulses 初始化為 0 且全檔無賦值 → if (HallPulsesLatch < 0) 恆為假， 這道保護從未生效。停車時最後一個霍爾邊緣若解碼成反向（夾煞回彈易造成），Speed 保持負值 （X2CScope 實測 −900 ＝ −0.62 km/h）直到 T1 逾時 840 ms。期間命令已為 0 而實測為負 → 速度環命令馬達往前出力 設為 3（100 馬達RPM ＝ 0.19 km/h），與上方兩個 ReGen 門檻同一刻度。殘值於一個 latch 週期（100 ms）內清除
4倒溜偵測拉鋸失效 連續計數遇同向邊緣即歸零。上坡與重力拉鋸（倒溜→推前一小段→再倒溜）每循環歸零，淨位移早已超標卻永不觸發 改為淨計數（反向 +1、正向 −1、地板 0）
5A04 / A19 警報碼對調 EMB 感測器異常掛在 A19、馬達霍爾異常掛在 A04，與規格相反 兩者對調回正確位置；Modbus LCD 錯誤暫存器補上 EMB 故障位元（bit 4）

#測項判定
1全速放油門的制動距離 最重要的安全迴歸。與 V0.18 對比，現值曲線 2 理論上約為 2.1 倍。不可接受就把 DECEL_FILTER_CURVE_SELECT 往大調（3～5）
2坡道倒溜量 UVW 判定調回 3 後唯一防線是 EMB_ROLLBACK_REV_EDGES = 90（157 mm）。超過可接受範圍就往下調
3段位 0（e-lock） 靜止＋滿油門、前進與倒退皆完全不動；EMB 保持夾住；切回段位 3 能正常起步（確認不會卡死在鎖定）
4行進中切到段位 0應平順減速到停，不可有帶速硬鎖的頓挫
5停車頓挫與煞車片異音應明顯改善（UVW_LOCK_STOP_PULSES 15→3 的目的）
6減速曲線確實生效切曲線 1 與 7，全程應有 1200 ms vs 240 ms 的明顯差異。已用 X2CScope 確認曲線 3 為 390 ms（理論 375 ms）
7命令確實到 0X2CScope 看 g_i16ScopeCmdOut 必須觸及 0。已確認
8上坡起步維持 V0.18 調校後的水準（增益未再變動）
9段位 1～5 上限2.76 / 4.15 / 5.53 / 6.91 / 8.29 km/h，未受影響
10Modbus 版本回報ID03 位址 0x0015 應回 0x0019
