速度曲線 (加速 / 減速) — 調參數說明

使用者版  |  專案 LWFDSPC  |  2026-07-31  |  所有參數皆為 #define，修改後需重新編譯燒錄才生效

0先讀這個：所有數字的單位

速度命令的單位是 Q15 命令 count（程式裡變數名雖是 RpM，但它不是 RPM）。換算：

1 count0.366 馬達 RPM0.018 輪 RPM0.00069 km/h
滿刻度 3276812000 馬達 RPM= SPEED_FS_RPM
常用值1500 count = 1.04 km/h
起步速度 OUTPUT_MIN		 12000 count = 8.29 km/h
段位 5 的上限		 實機頂速 ≈ 7.2 km/h
受母線電壓限制

參數表裡寫 RPMX10_TO_CMD(43945) 的意思是「馬達 4394.5 RPM 對應的 count」= 12000。要改成別的速度，改括號裡的 RPM×10 就好，不用自己算 count。

不要動 SPEED_FS_RPM（src/motor_scale.h : 40）。它是整個命令域的刻度，改了會等比改變所有加減速率與速度環 PI 增益，必須全部重算。檔案內已有 #error 護欄擋住連帶不一致。

1目前有兩套加速機制，先確認你在調哪一套

總開關：src/longwin/codeSw.h : 117

#define CODESW_THROTTLE_ACCEL_FILTER_ENABLE (1)   // 目前 = 1
設定值使用的機制加速參數在哪減速參數在哪
0 舊：step/time 查表
依油門電壓分 5 段		 第 3 節 第 4 節
兩套共用同一張減速表
1 目前 新：限斜率 + 濾波
5 組曲線，程式內選		 第 2 節
減速永遠走舊的 step/time 表。新機制只接管「加速」；放油門或需要減速時，程式內部會自動轉回舊的減速表，所以煞停行為在兩種設定下完全一樣。

2加速 — 新機制（限斜率 + 濾波）目前生效

結構：目標 → [限斜率 R] → [一階濾波 τ] → 速度命令。R 決定要幾秒到達，τ 只把折角磨圓（消掉起步與到頂時的階梯感）。

2-1. 選哪一組曲線（最常用的旋鈕）

src/longwin/s_logic_motor.h : 112

#define ACCEL_FILTER_CURVE_SELECT (4u)   // 1~5，目前 = 4

改這一個數字就換一組手感，範圍 1~5（超出範圍編譯會直接報錯，不會靜默出錯）。

曲線加速率到一半速度到 95%完全到頂說明
10.69 km/h/s5.50 s10.23 s12.12 s最緩
21.04 km/h/s3.75 s6.90 s8.73 s緩
31.38 km/h/s2.88 s5.24 s7.05 s與舊機制同手感
4 目前2.07 km/h/s2.00 s3.60 s5.40 s快
52.76 km/h/s1.57 s2.79 s4.60 s最快

上表為「由起步速度 1.04 km/h 加到 8.29 km/h」的實測模擬值。

2-2. 改曲線本身的參數

src/longwin/s_logic_motor.h : 132~139

#define ACCEL_FILTER_CURVE_TABLE_INIT                        \
    {   {2, 7, ACCEL_FILTER_START_CMD_DEFAULT},   /* 曲線 1 */ \
        {3, 7, ACCEL_FILTER_START_CMD_DEFAULT},   /* 曲線 2 */ \
        {4, 7, ACCEL_FILTER_START_CMD_DEFAULT},   /* 曲線 3 */ \
        {6, 7, ACCEL_FILTER_START_CMD_DEFAULT},   /* 曲線 4 */ \
        {8, 7, ACCEL_FILTER_START_CMD_DEFAULT} }  /* 曲線 5 */

每組是 { R, K, 起始速度 }：

欄位意義怎麼調
R每 2 ms 增加的 count
= 加速率		 要更快就加大、更慢就縮小。R 每 +1 約 +0.35 km/h/s。
對照：R=2→0.69、4→1.38、6→2.07、8→2.76 km/h/s
K磨圓程度
τ = 2K × 2 ms		 K=7 → τ=0.26 s（目前全部用 7）。+1 就是柔和一倍，代價是到頂多花約 τ 的時間。
K=6→0.13 s、7→0.26 s、8→0.51 s
起始速度一給油門就直接跳到這個速度，不從 0 慢慢爬 預設 RPMX10_TO_CMD(5493) = 1.04 km/h（s_logic_motor.h : 124）。
覺得起步遲鈍可調高，覺得起步「彈一下」可調低。每組曲線可各自設定。

3加速 — 舊機制（step/time 查表）目前未生效

依當下的油門電壓落在哪一段，決定用哪一組 {Step, Time}：每 Time 毫秒把命令加 Step 個 count。加速率 = Step ÷ Time。

注意這張表是刻意「油門轉越多、斜坡越緩」（1.38 → 0.86 km/h/s），用來避免大幅度需求時猛衝。
另外：油門起步門檻已改為 1200 mV，與第一段的門檻 V1_MV 相同，所以最緩的第 0 段 {2,1} 實際上碰不到，輕踩起步會直接落在第 1 段 {3,2}。要恢復最緩起步段，需把 V1~V4 往上搬（等比例為 1560/2370/3180/3990）。

6停車前的低速段（減速表管不到的區域）

命令減到很低之後，實際停止行為由這幾個門檻決定，停車震動或滑行太久要調這裡，不是調減速表。

參數現值位置說明
BrakeStartSpeedPulses15main.c : 3290.95 km/h 以上才允許回充煞車
BrakeStopSpeedPulses7main.c : 3300.44 km/h 以下停止回充煞車
UVW_LOCK_STOP_PULSES3src/userparms.h : 263 0.19 km/h 以下啟動三相短路煞停。調太低會拉大「回充停止(0.44)～短路開始」的空窗，鬆油門後會低速滑行才停
UVW_LOCK_RELEASE_REF500src/userparms.h : 258油門目標高於 0.35 km/h 才解除短路（遲滯，防來回切換）
EMBRAKER_SHORT_TO_LOCK_DELAY_MS50 mss_logic_embraker.h : 53 短路生效後多久上電磁煞車。停車還震就加大（給馬達更多時間停），鎖太慢就縮小

Pulses 的單位是「每 100 ms 的霍爾邊緣數」：1 pulse = 33.3 馬達 RPM = 0.063 km/h。

8調參數的建議流程

① 先決定用哪套機制
想要「一個數字換整組手感」→ 新機制（CODESW_THROTTLE_ACCEL_FILTER_ENABLE = 1），改 ACCEL_FILTER_CURVE_SELECT。
想要「不同油門開度給不同斜率」→ 舊機制（設 0），改 step/time 表。
② 一次只改一個數字
加速與減速分開驗，正轉與反轉分開驗。改完編譯燒錄再上車。
③ 用 X2CScope 看波形，不要只憑感覺
觀測 g_i16ScopeCmdTarget（油門要求的目標，轉油門時是階梯）、 g_i16ScopeCmdRateLim（限斜率後，新機制才有）、 g_i16ScopeCmdOut（實際送給馬達的命令）。三條疊在一起就能看出斜率與磨圓效果。
X2CScope 的時間軸在通訊忙碌時會被壓縮約 1.4 倍（取樣被跳過）。量絕對時間請一併觀測 g_u16X2cUpdateSkipCount，或改用相對比較（例如把斜率設一半，看波形是否剛好變兩倍）。
④ 症狀 → 該調哪裡
症狀調整方向
起步太衝 / 太鈍新機制：曲線的 R 或 ACCEL_FILTER_CURVE_SELECT；起步瞬間的彈跳感調起始速度
加速中段感覺不順、有階梯感新機制：加大 K（磨圓）。舊機制：檢查是否剛好跨在電壓分段邊界上
放油門後停太慢 / 滑行太久減速表的 {Step,Time}；若是最後一小段才慢，看第 6 節的低速門檻
停車瞬間震動加大 EMBRAKER_SHORT_TO_LOCK_DELAY_MS，或降低 UVW_LOCK_STOP_PULSES
放油門時「頓一下」才減速減速表第一段的 Step 太大；或油門死區 VOLTAGE_MIN_MV 太高
頂速不夠先量電池電壓。頂速受母線電壓限制（25 V 只到約 7.1 km/h），不是曲線問題，調段位上限無效
燒錄後第一次上車務必先做這三項：平路起步/停止、坡道起步（確認電磁煞車的倒溜保護有動作）、以及低速切換前進/後退。減速與煞車相關的參數改動屬安全項目。
