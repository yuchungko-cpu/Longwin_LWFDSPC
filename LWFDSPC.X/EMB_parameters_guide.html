1. EMB 動作準則(狀態機)

EMB 只在 WAITING_TO_LOCK(鬆油門、馬達準備停止)狀態判斷是否鎖定。共有三條鎖定路徑,由上到下優先:

優先條件動作對應參數
—重新給油門 bIsActive(命令 > 釋放門檻)釋放煞車,回 RELEASEDEMBRAKER_RELEASE_THRESHOLD_FWD/REV
1倒溜 bReverseEdgeDetected(反向霍爾邊緣)立即鎖定—(即時)
2UVW lock 生效 bUVWLockActive起算計時 → 達延遲 → 強制鎖定EMBRAKER_SHORT_TO_LOCK_DELAY_MS
3failsafe:UVW lock 未生效 + 命令歸零 + 逾時強制鎖定EMBRAKER_LOCK_TIMEOUT_MS
RELEASED ──鬆油門──▶ WAITING_TO_LOCK ──┬─ 倒溜 ───────────────────────▶ LOCKED ├─ UVW lock 生效 → 延遲 DELAY_MS ─▶ LOCKED (主路徑) └─ UVW未生效 → 逾時 TIMEOUT_MS ──▶ LOCKED (failsafe)
路徑 2 的計時從「UVW lock 生效的當下」起算,不是從鬆油門起算。路徑 3 的逾時則從鬆油門起算。兩者互斥:UVW lock 生效走路徑 2,沒生效才走路徑 3。

3. 動作參數(可調)

src/longwin/s_logic_embraker.h

參數現值單位說明
EMBRAKER_SHORT_TO_LOCK_DELAY_MS 1000ms ★ 主要旋鈕。UVW lock 生效後延遲多久才鎖 EMB。延遲要足夠讓馬達由 UVW 短路減速到完全停止,避免帶速鎖定造成騎乘震動。
EMBRAKER_LOCK_TIMEOUT_MS 1000ms failsafe:鬆油門後超過此時間仍未鎖(例如霍爾異常導致 UVW lock 從未生效)則強制鎖,確保 EMB 不會永遠不鎖。
EMBRAKER_RELEASE_THRESHOLD_FWD
EMBRAKER_RELEASE_THRESHOLD_REV		 1600
1600		命令值 馬達命令超過此值才「釋放」煞車讓馬達可轉。正/反轉可分開設。
EMBRAKER_FAULT_THRESHOLD_MV 1500mV IEMB 腳位電壓低於此值判定煞車感測器故障(A19),進入 FAULT 狀態並鎖定。
EMBRAKER_DIVIDER_R1 / _R2 10k / 100kΩ IEMB 分壓電阻,用於 ADC 值換算 mV。依實際硬體設定。

已停用(保留定義供參考)

參數說明
EMBRAKER_LOCK_SPEED_KMH_X10舊版「低於此車速鎖定」門檻。現行準則改用時間,不再比較速度。

4. 相依參數:UVW lock(決定路徑 2 何時觸發)

EMB 主路徑靠 bUVWLockActive 觸發,而 UVW lock 何時生效由以下參數決定。src/userparms.h

參數現值說明
UVW_LOCK_STOP_PULSES7進鎖脈衝門檻:HallPulsesLatch < 此值 視為接近靜止(7 ≈ 馬達 58 RPM,極對數 12)。已與 ReGen 的 BrakeStopSpeedPulses 分開,調此值不影響 ReGen 起煞點。
UVW_LOCK_ENTRY_CNTR30進鎖 debounce:命令歸零 + 低速連續 30 × 1ms = 30ms 才 latch。
UVW_LOCK_RELEASE_REF500解鎖門檻:油門目標 |TargetRpm| ≥ 此值則解除 UVW lock(遲滯)。
換算關係:pulses/100ms = 馬達RPM × 極對數(12) / 100。HallPulsesLatch 每 100ms 更新一次,是「過去 100ms 的霍爾脈衝數」。

5. 調整指引(常見情境)

症狀調整
馬達還在動就夾煞車、騎乘震動加大 EMBRAKER_SHORT_TO_LOCK_DELAY_MS(給馬達更多時間停)
停穩後太久才夾煞車縮小 EMBRAKER_SHORT_TO_LOCK_DELAY_MS
UVW lock 太晚生效(高速就想開始準備)加大 UVW_LOCK_STOP_PULSES(容許較高殘速進鎖)
UVW lock 進太早、殘速仍高縮小 UVW_LOCK_STOP_PULSES
斜坡停車會倒溜一小段才夾倒溜(Plan B)已即時處理;若仍不足,檢查霍爾方向偵測
重新給油門後煞車不放/太晚放調 EMBRAKER_RELEASE_THRESHOLD_FWD/REV
⚠ 安全注意:目前 failsafe(EMBRAKER_LOCK_TIMEOUT_MS)是「UVW lock 未生效」時的唯一保底。若霍爾感測器異常導致 UVW lock 一直不 latch,EMB 僅靠此逾時鎖定。測試時務必確認霍爾故障(A04)有其他保護接手,且逾時值不要設得過長。
