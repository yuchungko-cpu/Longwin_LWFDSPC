1. 修正:停車前後抽動 / UVW lock 進不去FIX · 已驗證

main.c:1984-1991

症狀

馬達停止後仍前後抽動。UVW 相位鎖定(短路)始終無法 latch。

根本原因(死結)

進鎖判斷用了瞬時 Speed(piInputOmega.inMeasure),而 Speed 在停車顫動時被污染:

  • Speed 只在霍爾邊緣更新,每個邊緣把 T1INTCnt=0,使「逾時歸零」路徑永不觸發。
  • 顫動週期極短時 HallPeriod <= HallMinPeriod → Speed = 32767(謊報滿速)。
  • → abs(Speed) 恆大於門檻 → 30ms debounce 一直被清零 → UVWLock 永遠 latch 不上 → FOC 持續對抗 → 繼續抖動。

修正

改用邊緣計數 HallPulsesLatch(每 100ms 脈衝數),對 32767 尖峰免疫;沿用煞車停止門檻 BrakeStopSpeedPulses (=7)。

- (abs(piInputOmega.inMeasure) < UVW_LOCK_SPEED_THRESHOLD);
+ (HallPulsesLatch < BrakeStopSpeedPulses);

驗證結果

✔ 實機測試:停車抽動已消除。

3. 審視:馬達堵轉保護(現況說明,未修改)REVIEW

main.c:2756-2827 · MotorStallDetect() · 每 20ms 執行

觸發條件(需同時成立)

  • 速度模式 uGF.CtrlMode == 0
  • 有驅動命令 |TargetRpm| >= MOTOR_STALL_COMMAND_THRESHOLD (1000)
  • 近乎不轉 |Speed| <= MOTOR_STALL_SPEED_THRESHOLD (Q15(0.03))

三段漸進動作

階段門檻(×20ms)時間動作
限流MOTOR_STALL_CURRENT_LIMIT_CNTR = 4008 秒電流降至 50% (MOTOR_STALL_CURRENT_LIMIT_PERCENT)
鎖定MOTOR_STALL_LOCK_CNTR = 300060 秒FaultFlags.MotorStall=1、uGF.Fault=1、切斷輸出 latch

解除

  • 明顯轉動 |Speed| >= Q15(0.06) 持續 500ms (MOTOR_STALL_RELEASE_CNTR=25) → 計數歸零解除限流。
  • latch 後須放開油門(TargetRpm==0)才清除 fault。

備註:偵測用 Speed,但真正堵轉時無霍爾邊緣 → Speed 被 T1 逾時歸零 → 正常偵測,不受顫動尖峰問題影響。
